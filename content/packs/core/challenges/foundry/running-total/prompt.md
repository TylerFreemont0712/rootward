# The Running Total

The Tally Wisp keeps the Guild's accounts and forgets the total between entries.

Each line of input holds one integer. After each number, print the total of all the numbers so far. When the input
ends, print `max` and the largest total you printed. Skip blank lines. If there are no numbers at all, print nothing.

```
input:  5
        -2
        10
output: 5
        3
        13
        max 13
```
