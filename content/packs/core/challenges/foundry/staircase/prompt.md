# The Staircase

The Off-By-One Goblin builds staircases down into the Machine, and every one of them is a step short.

The input is one integer `n`. Print a staircase of `n` steps: line `i`, for `i` from 1 to `n`, holds `i` copies of `#`
pushed to the right with spaces, so that every line is `n` characters wide. If `n` is 0 or negative, print nothing.

```
input:
4

output:
   #
  ##
 ###
####
```
