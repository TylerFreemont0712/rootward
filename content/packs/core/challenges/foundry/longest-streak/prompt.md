# The Longest Streak

The Tally Wisp watches the Guild's dice rolls and keeps losing count of the repeats.

Each line of input holds items separated by whitespace. Print the length of the longest run of equal items that sit
next to each other, followed by the item, as `length item`. When two runs are equally long, report the one that comes
first. A line with no items prints `0`.

```
input:  a a b b b c
        x y z
        4 4 4 4
output: 3 b
        1 x
        4 4
```
